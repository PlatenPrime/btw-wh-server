# Фронтенд: зона и остаток в asks pulls

## Задача

На экране снятия по `GET /api/asks/pulls` (и `GET /api/asks/:id/pull`) сразу показывать **зону хранения артикула**, **сколько есть на паллете** и **сколько снять** — без доп. запросов к arts.

Полный контракт: [`docs/api/asks.md`](../api/asks.md).

## Новые / явные поля позиции

| Поле | Тип | Смысл для UI |
|------|-----|----------------|
| `artZone` | `string \| null` | Зона артикула из справочника Arts (`null` если Art нет) |
| `quant` | `number` | Сколько есть на этой позиции паллеты |
| `plannedQuant` | `number \| null` | Сколько снять с этой позиции (`null` если в заявке не указан quant) |

`artZone` ≠ `Ask.zone` (опциональное поле заявки). Источник — `Art.zone` по `askArtikul`.

## UX

1. В карточке/строке позиции: `artZone` (или «—» / empty при `null`).
2. Рядом: «есть `quant` / снять `plannedQuant`» (если `plannedQuant === null` — режим без целевого количества).
3. Не ходить в `/api/arts` только ради зоны на этом экране — поле уже в ответе pulls.

### Не делать

- Не путать `artZone` с сектором паллеты (`palletData.sector`) и с `Ask.zone`.
- Не считать отсутствие `artZone` ошибкой API — Art может отсутствовать; UI показывает empty state.
